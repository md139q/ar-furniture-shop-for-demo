## ✨ Key Features
* **Augmented Reality Room Placement:** Place, rotate, and scale 3D furniture models (`.glb` / `.gltf`) on real-world surfaces using Google ARCore with WebXR fallback support.
* **2D-to-3D Asset Pipeline:** Supports MeshyAI-generated 3D furniture models alongside standard product galleries.
* **Full E-Commerce Flow:** Category browsing, product customization, real-time shopping cart, order tracking, and automated inventory sync via Cloud Firestore.
* **Authentication & Security:** Firebase Authentication with role-based Firestore Security Rules and Cloud Functions support.
* **Payment Gateway Ready:** Pre-structured webhook/checkout integration ready for HitPay, PayMongo, or Stripe.
* **Cross-Platform Build Ready:** Configured for Android, iOS (via Codemagic CI/CD), and Progressive Web App (PWA) deployment.
